Funciones experimentales

Acá cargás los datos para que el sistema avise las llegadas tarde por Telegram y por correo. Son funciones opcionales: si no las configurás, el resto del sistema funciona igual.

Avisos por Telegram

¿De dónde saco estos datos?
  1. En Telegram buscá @BotFather, escribile /newbot y seguí los pasos. Al final te da el token.
  2. Creá un grupo (o usá uno existente) y agregá a tu bot.
  3. Para saber el ID del chat, escribí un mensaje en el grupo y abrí https://api.telegram.org/bot<TOKEN>/getUpdates. Buscá el número que aparece en "chat":{"id": ...}.
{% if config.TELEGRAM_BOT_TOKEN[0] == 'entorno' %}Hoy se usa el token de las variables de entorno del servidor.{% endif %}
Guardá los datos primero. La prueba usa lo que está guardado.

Avisos por correo

{% if config.SMTP_HOST[0] and (config.SMTP_FROM_EMAIL[0] or config.SMTP_USERNAME[0]) %} Configurado {% else %} Sin configurar {% endif %}

Los avisos se envían al correo que cada alumno tiene cargado en su usuario.

¿Qué datos pongo?

Son los datos de tu proveedor de correo. Por ejemplo, para Gmail: servidor smtp.gmail.com, puerto 587, tu dirección como usuario y una clave de aplicación (no tu contraseña normal) como contraseña.

Guardá los datos primero. La prueba usa lo que está guardado.

Las claves no se vuelven a mostrar una vez guardadas. Se guardan en la base de datos, así que también quedan dentro de las copias de seguridad: guardalas en un lugar seguro.
