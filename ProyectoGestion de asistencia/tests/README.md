# Planillas de ejemplo

`alumnos_ejemplo_1.xlsx` y `alumnos_ejemplo_2.xlsx` son datos completamente ficticios para probar la carga masiva. Cada hoja incluye encabezados de nombre, apellido, DNI, correo, contraseña inicial, curso, turno y capacitación.

En la pantalla **Carga masiva de alumnos**, selecciona uno de los archivos, asigna cada encabezado al campo correspondiente, valida la vista previa y confirma. Al confirmar se crea primero una copia de seguridad en `backup_db/`.

Las contraseñas de estos ejemplos son demostrativas: no reutilizarlas en cuentas reales. Los DNI están guardados como texto en Excel para conservar posibles ceros iniciales.
